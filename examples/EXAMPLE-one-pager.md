# Example reports — the gold standard for a full research report

When the user asks for a full research report, match the **depth, structure, voice, and formatting** of these. Two sources, use both:

## 1. Bundled golden reports (offline, always available)
Eight finalized reports ship in this folder. Read them before writing a report and mirror their shape:

- `GOLDEN-SOGNI-ai.md` — Sogni AI ($SOGNI), a deep low-cap research dive
- `GOLDEN-zama-notion-entry.md` — Zama ($ZAMA)
- `GOLDEN-XLM-stellar.md` — Stellar ($XLM)
- `GOLDEN-AERO-aerodrome.md` — Aerodrome Finance ($AERO)
- `GOLDEN-ETH-ethereum.md` — Ethereum ($ETH)
- `GOLDEN-LINK-chainlink.md` — Chainlink ($LINK)
- `GOLDEN-TAO-bittensor.md` — Bittensor ($TAO)
- `GOLDEN-VIRTUAL-virtuals-protocol.md` — Virtuals Protocol ($VIRTUAL)

Plus `STYLE-GUIDE-notion-entry.md` — the rules behind the format.

## 2. The live gold standard — the public CoinPicks Diamond Investment Database
The six Diamond reports above are snapshots of this published, member-readable database. For the **latest** versions (and any new entries added since this zip was built), point Claude at:

`https://coinpicks.notion.site/diamonddatabase?v=27e82822b7b780409672000cc47c0665`

**Read it through the Claude for Chrome browser, not a plain fetch.** It's a published Notion site (JavaScript-rendered) — a normal web fetch returns an empty "Notion" shell with no content, exactly like the Skool course pages. Open the link in the browser, click into the individual coin entries, and read the full page of each.

## The shape every report follows
Chart link → Liquidity (two lines only) → **Overview** (angle-first, plain language, a "What $TICKER does" callout, and an everyday analogy) → **Exclusivity Factor** (Ease of Use / Hair-on-Fire / Exclusivity) → **Narrative Scoring** (Maturity, Smart Money, Communication, Lineage, Mutation — written as prose) → **Team** (one sentence per person, past employers only, sourced Ctrl+F quotes) → **Want to Know More?** → **Extra** (risks, funding history **with dates and overhang analysis**, catalysts). H1 section headers are wrapped in `<span color="yellow_bg">…</span>`.

**No numeric scores in the body. Lead with the angle. Never invent a number** — match the thoroughness of these examples, not their specific facts.
